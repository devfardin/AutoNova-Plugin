# 🚗 AutoNova – Automotive WordPress Project (RODIUS CARS)

## 📌 Project Overview
**AutoNova** is a modern and premium WordPress solution built for automotive businesses such as car dealerships and vehicle solution providers.

This project is developed for **RODIUS CARS**, focusing on a clean, high-end design with dynamic functionality for managing car inventory, services, and customer interactions.

---

## 🎯 Objectives
- Build a professional **5-page website**
- Deliver a **premium automotive UI/UX**
- Ensure full **mobile responsiveness**
- Enable easy **content management (CMS)**
- Integrate **lead generation features** (CTA, WhatsApp, forms)

---

## 🧱 Project Structure

### 🧩 Theme: AutoNova
Handles all design, layout, and UI/UX elements.

### ⚙️ Plugin: AutoNova Core
Handles dynamic functionality and content management.
